# Design and frontend demo

Інтерактивна демонстрація до слайда «Спитай мачурного»: приклади поведінки інтерфейсу на різних ширинах екрана.

Відкрийте `index.html` у браузері. Повзунком або кнопками можна змінювати ширину прикладів; деякі приклади мають додаткові перемикачі мови, кількості тексту або способу масштабування фону.

Приклади навмисно демонструють проблеми адаптивності, зокрема перенесення та накладання вмісту, обрізання фону і втрату чіткості зображень. Зовнішні залежності та збірка не потрібні.
