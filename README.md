# Дизайн і фронтенд

Інтерактивні приклади про те, як дизайнерські рішення поводяться в інтерфейсі на різних ширинах екрана.

Відкрийте `index.html` у браузері або запустіть локальний статичний сервер. На головній сторінці — чотири теми. Демонстрація адаптивності розташована в `adaptive/`; сторінки інших тем підготовлені для майбутніх прикладів.

Зовнішні залежності та збірка не потрібні. Деякі приклади навмисно показують проблемну поведінку інтерфейсу.
