# Дизайн і фронтенд

**Навчальний сайт з інтерактивними прикладами про те, як дизайнерські рішення працюють у браузері.** Він допомагає дизайнерам і розробникам обговорювати поведінку інтерфейсу ще до реалізації: що відбувається зі змістом на різних екранах, як змінюється макет і які правила варто узгодити команді.

## Що всередині

### [Адаптивність](adaptive/)

Дванадцять прикладів показують, як ширина екрана впливає на меню, картки, фільтри, зображення, текст, кнопки й таблиці. Змінюйте ширину повзунком або обирайте готові значення та порівнюйте результати. Деякі приклади навмисно демонструють проблемну поведінку; поруч наведено поради для команди.

### [Контент і локалізація](localization/)

Порівняйте короткі й довгі написи, український і німецький тексти та напрямки письма. Приклади допомагають продумати поведінку кнопок, довгих слів, тексту й зображень у різних мовних версіях.

### [Токени, сітки та відступи](tokens-spacing/)

Інтерактивні демонстрації пояснюють візуальний ритм, спільні значення дизайн-токенів і роботу колонок у контейнері. Тема також розкриває, як узгоджені рішення впливають на користувачів і бізнес.

### [Структура макета у Figma](figma-structure/)

Приклади показують, чому важливі назви та ієрархія шарів, як Auto layout описує поведінку вмісту і як спільні типографічні стилі допомагають команді працювати послідовно.

## Як запустити

Відкрийте [головну сторінку](index.html) у браузері. Також можна запустити локальний сервер із кореня проєкту:

```bash
python3 -m http.server 8000
```

Після цього перейдіть на [localhost:8000](http://localhost:8000).

Сайт створено на HTML, CSS і JavaScript. Встановлювати залежності або збирати проєкт не потрібно.

## Структура проєкту

```text
index.html          Головна сторінка з темами
adaptive/           Приклади адаптивності та їхні зображення
localization/       Контент і локалізація
tokens-spacing/     Токени, сітки та відступи
figma-structure/    Структура макета у Figma
```
